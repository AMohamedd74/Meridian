# Product Specification

## 1. Product vision

Purpose helps people who have multiple possible directions but struggle to decide what to pursue.

The product does not promise to find one perfect answer.

Instead, it helps users:
- understand themselves,
- identify promising directions,
- test those directions,
- collect evidence,
- and decide what to do next.

## 2. Target user

Initial target:

Ambitious people roughly 20–35 who:
- feel stuck or directionless,
- are considering a career change,
- have multiple interests,
- are considering entrepreneurship,
- or are capable of several different paths but struggle to commit.

## 3. Core user journey

Landing page
→ Start conversation
→ Adaptive AI exploration
→ Profile generation
→ Analysis/loading state
→ Three directions
→ Select direction
→ Path detail
→ Roadmap
→ Dashboard
→ Experiment/tasks
→ Weekly check-in
→ Updated profile/direction

## 4. Product principles

### Direction, not destiny
Recommendations are possibilities, not predictions.

### Evidence over introspection alone
Users should test paths through real-world experiments.

### Small next steps
The product should reduce overwhelm by making the next action concrete.

### Adaptive
The roadmap and direction can change as new evidence is collected.

### Explainable
Users should understand why a direction was suggested.

### Human
The AI should sound thoughtful and conversational, not clinical or robotic.

## 5. MVP success criteria

The MVP should allow a new user to:
- start an exploration,
- complete an AI conversation,
- receive three meaningful directions,
- select one,
- receive an actionable roadmap,
- complete tasks,
- submit a check-in,
- and see the direction/plan update.

## 6. Primary validation questions

The MVP exists to test:
1. Do users enjoy the conversation?
2. Do users feel understood?
3. Do the three directions feel relevant?
4. Do users choose a direction?
5. Do users actually perform the first experiment?
6. Do users return for a check-in?
7. Does feedback make the updated direction feel more accurate?
