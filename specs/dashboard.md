# Dashboard Specification

## Objective

The dashboard is the user's living view of their current direction and next actions.

It should feel like a personal operating system, not a generic project-management dashboard.

## Required sections

### Current direction
Show:
- selected path
- exploration level/current confidence
- short explanation

### Current focus
One primary focus for the current period.

### This week
Show actionable tasks.

### Current experiment
Show:
- experiment title
- progress
- time remaining where applicable
- continuation action

### What we've learned
Show concise AI-generated insights grounded in user interactions.

### AI insight
Show one useful observation or emerging pattern.

### Recent feedback
Show recent check-in information.

## Acceptance criteria

- [ ] Dashboard loads from persisted data.
- [ ] Current path is shown.
- [ ] Tasks reflect roadmap state.
- [ ] Task completion updates persistence.
- [ ] Current experiment is visible.
- [ ] Insights are displayed.
- [ ] Empty states are handled.
- [ ] Dashboard is responsive.
