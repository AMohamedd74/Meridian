# Analytics Specification

Track only product events necessary for MVP validation.

## Events

- `landing_viewed`
- `conversation_started`
- `conversation_completed`
- `profile_generated`
- `paths_generated`
- `path_selected`
- `experiment_started`
- `task_completed`
- `experiment_completed`
- `check_in_started`
- `check_in_completed`
- `direction_updated`

## Core funnel

Landing
→ conversation started
→ conversation completed
→ paths generated
→ path selected
→ experiment started
→ experiment completed
→ check-in completed
→ direction updated

## Primary metric

The most important early metric is:

**Percentage of users who complete their first real-world experiment.**

Secondary metrics:
- conversation completion
- path selection
- return/check-in rate
- roadmap engagement
- task completion
